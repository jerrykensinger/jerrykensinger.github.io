# jerrykensinger.com

Personal site for Jerry Kensinger, hosted with GitHub Pages.

## Pages
- Home
- About
- Career
- Projects
- Tech
- Contact
- Custom 404 page

## Features
- Responsive navigation
- Light/dark mode with saved preference
- Automatic current year in the footer
- SEO and social sharing metadata
- Google Analytics
- Downloadable vCard
- Favicon and Apple touch icon
- Sitemap and robots.txt
- Preserved custom domain via CNAME

## Deploy
Copy these files to the root of the `jerrykensinger/jerrykensinger.github.io` repository and commit them to the `main` branch.

The existing `CNAME` is included and must remain in the repository so `jerrykensinger.com` continues to work.
