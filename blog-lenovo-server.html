How I Turned an Old Lenovo Desktop Into a Home Server

Instead of letting an older computer collect dust, I gave it a new job: serving files, watching my websites, and becoming a foundation for future home automation and backups.

It started with a computer that still had something to offer

My Lenovo IdeaCentre 710-25ISH was no longer my everyday PC. But with an Intel Core i5-6400 processor and 16 GB of RAM, it still had more than enough capability for lightweight, always-on tasks. Throwing it away or leaving it in storage felt like a waste.

At the same time, I had files and photos scattered across iCloud, Google Photos, and OneDrive, plus a growing collection of website and automation projects. I wanted a place to learn, experiment, and eventually bring those pieces together.

The idea: reuse the hardware I already own.

Not every useful server starts as a new server. Sometimes it starts as a perfectly good old desktop with a different operating system and a new purpose.

Giving the Lenovo a second life with Linux

I moved the desktop from Windows to Ubuntu Server, choosing a lean system I can manage remotely rather than keeping a full desktop environment running. Ubuntu lives on a 1 TB SSD, while a separate SSD of roughly 2 TB provides room for server data and shared files.

The machine now runs without needing a dedicated monitor or keyboard for normal operation. I connect securely over SSH from my Mac mini or MacBook Pro when I need to check or maintain it. That also means I can keep using my main computers while the Lenovo handles background jobs.

What we have working so far

The first milestone was getting a reliable foundation in place: remote access, organized storage, and shared folders available on my home network. From there I installed Docker and Docker Compose, which make it easier to run and manage independent services.

The first real service is Uptime Kuma, a dashboard that helps me monitor the availability of my websites and other services. It is running on the Lenovo, with its management interface kept private. I also enabled disk-health checks using SMART tools, with alert delivery still being tested and refined.

Working now

Ubuntu Server • SSH remote access • SSD-based storage • Local network file shares • Docker & Compose • Uptime Kuma • Disk-health monitoring

What is next, and what is not finished yet

The bigger goal is a centralized backup system for family photos and important files, with both local and cloud copies. That will require careful planning around duplicates, storage capacity, automatic syncing, and recovery testing. Installing a server is not the same thing as having a complete, verified backup system.

I also want to keep expanding uptime monitoring for my website projects, explore a UPS battery backup and safe shutdown process, and use AI-assisted terminal tools to help inspect and maintain the machine. For those tools, my rule is simple: read-only diagnostics can run automatically, but changes require my approval.

The lesson so far

Repurposing this Lenovo has been as much about learning as saving money. I am getting hands-on experience with Linux, storage, remote management, containers, and monitoring, while putting hardware I already owned back to work.

The best part is that the project can grow a little at a time. It does not have to be a perfect home lab on day one. It just has to be useful, secure, and more capable with each step.
